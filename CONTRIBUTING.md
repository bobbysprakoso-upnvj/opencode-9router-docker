# Contributing

Contributions are welcome.

## Guidelines

- Do not commit credentials, API keys, tokens, or `.env` files.
- Keep examples provider-agnostic where possible.
- Test Docker Compose changes before submitting.
- Document breaking configuration changes.
- Keep security-sensitive defaults conservative.

## Pull Requests

Before submitting a pull request:

1. Validate Docker Compose configuration.
2. Check that no secrets are included.
3. Update documentation if behavior changes.
4. Describe the purpose of the change clearly.
